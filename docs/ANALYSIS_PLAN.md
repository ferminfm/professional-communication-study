# Best-effort analysis plan

## Scope

This study is intended to improve a real naming decision at low cost. It is not designed to estimate population-wide preferences with survey-sampling precision.

## Evidence hierarchy

1. Legal/commercial clearance: a material rights/confusion problem can eliminate a name regardless of survey preference.
2. Serious human-use failures: pronunciation/transmission failure, strong unrelated-category confusion, or repeated confusion with an existing entity.
3. B2B fit: professional credibility, clarity in context, willingness to inspect a proposal, and perceived geographic origin.
4. Memorability and distinctiveness.
5. Founder preference as a legitimate tie-breaker among names that pass the first four gates.

## Current founder prior

The founder currently feels strongest about:

- Ensenada Flow
- Baja California Fluid Dynamics

Ensenum and Enseflow remain in the instrument so the study can still falsify that preference or provide useful contrast.

## Recruitment target

Do not impose an expensive quota. A reasonable best-effort stopping target is:

- 12–20 technically informed or industrial contacts across the founder network;
- 10–20 general contacts who do not already know the project well;
- several Japanese-speaking respondents if available through personal/academic/professional contacts;
- optional organic social-media respondents.

A total of roughly 25–50 usable responses is enough for this decision-support purpose if comments and quantitative signals are reasonably consistent. If only 15–25 good responses are obtainable, analyze them transparently rather than paying for a large panel.

## Avoid false precision

Do not report a single composite 'winner score'. Report:

- counts / proportions for final choices;
- medians and distributions for 1–7 ratings;
- pronunciation/spelling failure patterns;
- geographic inferences;
- repeated spontaneous associations/confusions;
- results by language and technical-vs-general cohort where sample sizes permit.

Small groups should be described qualitatively rather than with pseudo-precise percentages.

## Decision rule

After legal/commercial checks:

- Eliminate a candidate if the study reveals a repeated serious transmission/confusion problem that would materially impair business use.
- If both Ensenada Flow and Baja California Fluid Dynamics remain viable, compare their trade-off directly: distinctiveness/brandability versus explicit technical/geographic clarity.
- Use Ensenum/Enseflow as challenger evidence, not as forced finalists.
- If evidence is close, founder preference can decide; there is no requirement that a small convenience sample override the founder's own strategic judgment.
